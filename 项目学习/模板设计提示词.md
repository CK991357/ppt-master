### 2.2 字体方案
- **字体栈**：`[例如：system-ui, -apple-system, "Segoe UI", Roboto, sans-serif]`（推荐系统 UI 字体）
- **封面标题字号**：`[例如：56px]`
- **页面标题字号**：`[例如：36px]`
- **正文字号**：`[例如：20px 或 24px]`（根据内容密度选择）

### 2.3 品牌资产（提供文件）
- **Logo 文件**：`[提供 logo.png 或 logo.svg，要求透明背景]`
- **其他装饰图形**：`[可选，如背景纹理、分割线图案]`
- **参考设计文件**：`[可选，现有 PPTX 或截图]`

### 2.4 布局偏好（可选，若不提供则采用标准布局）
- **封面风格**：`[全屏背景 / 居中卡片 / 左对齐大标题 / 带斜纹装饰]`

## 3. 输出文件要求

请生成以下文件，全部放入 `templates/layouts/[模板ID]/` 目录：

   - 内容需与上述填写的设计规范一致。

2. **`01_cover.svg`**（封面页）  
   - 使用占位符：`{{TITLE}}`, `{{SUBTITLE}}`, `{{DATE}}`, `{{AUTHOR}}`。
   - 若包含 Logo，用 `<image href="logo.png" .../>` 引用（文件会单独提供）。

3. **`02_chapter.svg`**（章节页）  
   - 使用占位符：`{{CHAPTER_NUM}}`, `{{CHAPTER_TITLE}}`，可增加 `{{CHAPTER_TITLE_EN}}`。

4. **`02_toc.svg`**（目录页，可选但强烈推荐）  
   - 使用索引占位符：`{{TOC_ITEM_1_TITLE}}`, `{{TOC_ITEM_1_DESC}}` 等（至少支持 6 项）。
   - 样式需清晰列出章节名称和页码（页码可放在描述中或单独占位符）。

5. **`03_content.svg`**（内容页）  
   - 固定页眉（含 `{{PAGE_TITLE}}`）和页脚（含 `{{PAGE_NUM}}`, `{{SOURCE}}`）。
   - 内容区留空或放置虚线框和 `{{CONTENT_AREA}}` 占位符，执行师会在此自由绘制。

6. **`04_ending.svg`**（结尾页）  
   - 使用占位符：`{{THANK_YOU}}`, `{{ENDING_SUBTITLE}}`, `{{CLOSING_MESSAGE}}`, `{{CONTACT_INFO}}`, `{{COPYRIGHT}}`。

7. **品牌资产文件**（如果提供了 logo 等）  
   - 直接复制到模板目录，SVG 中使用相对路径引用。

## 4. 技术约束（必须严格遵守）

- **viewBox**：所有 SVG 必须为 `0 0 1280 720`。
- **背景**：使用 `<rect>` 元素，禁止 `<style>` 或 `class`。
- **透明度**：使用 `fill-opacity` / `stroke-opacity`，禁止 `rgba()`。
- **文本换行**：使用 `<tspan>`，禁止 `<foreignObject>`。
- **禁止元素**：`clipPath`, `mask`, `<style>`, `class`, `foreignObject`, `textPath`, `animate*`, `script`, `marker`, `marker-end`。
- **阴影/发光**：允许使用 `<filter>`（`feGaussianBlur` + `feOffset`），会被转换为 PPT 效果。
- **图标**：不要直接嵌入路径，使用 `<use data-icon="...">` 占位符（后处理自动嵌入）。
- **图片引用**：使用 `<image href="filename.png"/>`，后处理时路径会自动修正。
- **Logo 放置**：在封面和内容页页眉适当位置加入 `<image>` 引用。

## 使用说明

1. **复制提示词**到你的 AI 对话窗口（如 Claude、ChatGPT、Cursor 等）。
2. **填充所有 `[方括号]` 内容**，根据你的品牌需求填写颜色、字体等。
3. **附加素材文件**：将 logo.png、参考设计文件等上传给 AI（如果支持文件上传）。
4. **发送**，AI 将生成完整的模板文件。
5. **将生成的 SVG 和 design_spec.md 保存到** `skills/ppt-master/templates/layouts/[模板ID]/`。
6. **更新 `layouts_index.json`**（根据 AI 输出的 JSON 块手动添加或让 AI 输出完整文件）。
7. **运行验证命令**，确认无错误。

## 注意事项

- **AI 可能无法直接打包 ZIP**，但它会输出每个文件的内容。你需要手动创建目录和文件，或使用脚本批量写入。
- **如果 AI 输出 SVG 代码中包含 `xmlns:inkscape` 等不必要属性**，你可以要求它简化（移除专有命名空间）。
- **验证步骤很重要**：运行 `svg_quality_checker.py` 确保没有禁用元素。
